# Клиенты Гуляша — реестр для продаж

Полный список сетей доставки на платформе **Goulash** (goulash.tech): сайт, число точек, города, контакты. Для B2B-предложения доп-софта и AI-доработок клиентам Гуляша.

## Цифры
- **326 реальных сетей** (реестр 387 партнёров минус dev/test-стенды вендора)
- сайт у **253**
- филиалы у **206**, суммарно **951 точек**
- телефон у **240**, VK у **198**, Telegram у **96**, email у **111**

## Файлы
- `clients.csv` — таблица (Excel): сеть, сайт, точек, города, телефоны, Telegram, WhatsApp, VK, Instagram, Email, платформа
- `clients.md` — то же, читабельно
- `clients_full.json` — полные данные
- `index.html` — интерактивная страница (поиск, фильтры, сортировка по точкам)
- `partners_source.json` — первоисточник (`api.shared.goulash.tech/partners.json`)

## Источники (всё публичное)
- Реестр сетей — публичный `api.shared.goulash.tech/partners.json` (пикер «выбор организации» в приложении «Сотрудник СУ» / Goulash.courier).
- Точки, города, контакты — публичный `/api/cities` витрин Гуляша + подвалы/контакты сайтов.
